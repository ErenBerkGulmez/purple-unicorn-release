# Purple Unicorn 💜

Windows masaüstünde yaşayan küçük unicorn ve arkadaşı.

## İndir

**[Son sürümü indir](https://github.com/ErenBerkGulmez/purple-unicorn-release/releases/latest)**

Release sayfasındaki `purple-unicorn-...-setup.exe` dosyasını indirip kur.

- Pencerenin kenarlarını veya köşelerini sürükleyerek boyutunu ayarlayabilirsin. Karakterler, isim etiketi ve menü birlikte ölçeklenir.
- Menü → Ayarlar → **Görev çubuğuna oturt** ile ekranın altına yerleştirebilirsin.
- Menü → Ayarlar → **Güncellemeleri kontrol et** ile yeni sürümü bulup indirebilirsin.
- Kişisel kayıtlar bilgisayarında saklanır.

Bu depo uygulama indirmeleri ve güncelleme dosyaları içindir. Kaynak kodu burada paylaşılmaz.

Yeni sürümlerin imzalı kurulum paketi ve `latest.json` güncelleme bilgisi birlikte yayımlanır. Uygulama yeni sürümleri doğrudan bu dosyadan kontrol eder; kullanıcının GitHub hesabına veya Actions erişimine ihtiyacı yoktur.
